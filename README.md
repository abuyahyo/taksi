# 🚕 Tez Taxi — inDrive услубидаги такси дастури

Яндекс Такси кўринишида, inDrive услубида ишлайдиган веб-дастур.
Йўловчи нархни ўзи таклиф қилади, ҳайдовчилар рози бўлади ёки ўз нархини беради.

## Тузилиши

```
taxi-app/
├── backend/    # Node.js + Express + Socket.io + PostgreSQL
└── frontend/   # React + Vite + Leaflet харита
```

## Ишга тушириш

### 1. Backend
```bash
cd backend
npm install
createdb taxi_app
psql -d taxi_app -f src/config/schema.sql
cp .env.example .env   # маълумотларни ўзгартиринг
npm run dev            # http://localhost:5000
```

### 2. Frontend (янги терминалда)
```bash
cd frontend
npm install
npm run dev            # http://localhost:5173
```

## Саҳифалар

| Йўл | Саҳифа |
|-----|--------|
| `/` | Рол танлаш |
| `/yolovchi` | Йўловчи — буюртма ва нарх таклифи |
| `/haydovchi` | Ҳайдовчи — буюртмаларни кўриш ва қабул |
| `/admin` | Админ панели (фақат admin роли) |

## Тайёр функциялар

- ✅ Рўйхатдан ўтиш / Кириш (JWT)
- ✅ Харита, манзил танлаш (Leaflet)
- ✅ Нарх таклифи (inDrive услуби)
- ✅ Реал вақт алоқаси (Socket.io)
- ✅ Сафар ҳолатлари + GPS текшируви
- ✅ Баҳолаш тизими
- ✅ Админ панели + шаффоф блоклаш
